# Dice Roller VR — support site

Static, public App Store support and privacy pages for Dice Roller VR.

When this folder is published with GitHub Pages from the `main` branch root, the two App Store URLs are:

- `https://<github-user>.github.io/dice-roller-vr-support/privacy.html`
- `https://<github-user>.github.io/dice-roller-vr-support/support.html`

Only these static public files belong in this repository. Do not add app source code, screenshots containing personal material, certificates, provisioning profiles, API keys, or other credentials.
